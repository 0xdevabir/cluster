# Runbooks

One runbook per alert. A runbook exists so that responding to a page never
requires guessing — see Law V (Fail Loudly, Recover Silently) in
`ULTIMATE-PLAN.md#3-the-ten-laws-of-nexus`: the platform's control loops
handle failures automatically, and humans read post-hoc reports here rather
than improvising under pressure.

Populated starting with the observability and auto-remediation phases
(Phase 11 onward). Empty in Phase 00 by design.
